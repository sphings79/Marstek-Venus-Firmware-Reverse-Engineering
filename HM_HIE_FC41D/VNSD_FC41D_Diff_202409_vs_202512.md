## 1. Removed in 202512

| What | Details |
|---|---|
| **AirKiss** (WeChat smartconfig) | complete `airkiss_*` routines + lib `airkiss-2.0.0-25360`, AT+QAIRKISS, URC `+QAIRKISS:SSID=…,PSK=…` |
| **Web config page** (SoftAP web server) | AT+QWEBCFG, `192.168.19.1`, HTML form "FC41D smart config" (SSID, password, UART baud rate), `/index.htm`, `/not_connect.html`, `/connect_succes.html` – the web server / captive portal is gone |
| Flash init debug output | `[Flash]id:…`, `write status reg`, `choose default config` |
| various debug strings | `sctrl_sta_ps_init`, `bk_misc_init_start_type`, `+QSTAST:STATION_DOWN` |

→ From 202512 on, the module can **no longer** be configured via smartconfig/web page; only via AT commands / Control over UART.

## 2. New in 202512

| What | Details |
|---|---|
| **Signed FOTA** | `QLSECFOTA!!!` header, `ql_secfota_*` (move_file, analys_file, verify_ecdsa384_signature, calculate_file_sha384), embedded **ECDSA-P384 public key** (PEM @0x000ec8c2), "FOTA Signature verification succeeded/failed". Old, unsigned RBL packages are therefore rejected. |
| New AT commands (Quectel standard) | `AT+QREDDAVN`, `AT+QAPCFG="linknum"`, `AT+QSECCFG="log_ctl"`, `AT+QSTAINFORAW`, `AT+QBLEMTUMODE`, `AT+QHTTPGET/PUT` timeout range (10–65535 instead of 60–65535), `AT+QSSLCERT` with length + checksum |
| SSL HAL | `HAL_SSL_Establish/Read/Write` (mbedTLS client), `ql_socket_ssl_session_setup`, `ql_cert_data_is_exist/init` |
| BLE | `app_sec.c` (GAPC bond/pairing/LTK/TK handlers), `app_ble_set_le_pkt_size`, MTU mode configuration, extended `+QBLEPEERINFO` / `QL BLE:…mtu` output |
| SNTP | timer error handling, servers `pool.ntp.org`, `ntp1.aliyun.com`, `210.72.145.44` (fallback list) |
| Persistent user config | `usr_config_read/write_id_flash`, `usr_config_search_tab`, `save_user_info_tab_to_flash` (@0x00076228), flash partitions 7/8/9: TLV table (default baud rate 115200 = 0x1c200, SSID, PSK **AES-encrypted**, flags), CRC/checksum, **backup copy**, "redflag" marker |
| Dev debug (`lyy debug`, `[cx]`) | initials of the Quectel/Hame developers, considerably more occurrences in 202512 (SSID repeat check, `g_my_ssid`, `g_connect_key`, `uart_band`, `sleep_mode`, `flash_len`, `calcuCrc`) |
| Miscellaneous | `AT+HMIOPEN` usage text now shows `AT+HMIOPEN=1/0,ip,remote,local`; shell commands `echo`, `memdump`, `memp`; extended MQTT logging |

## 3. Unchanged (Hamedata customizations)
`AT+HMIOPEN` / `hame_tcp` / `hame_tcp_connect_server_command`, `connect_key`, default WLAN `hellow` / `12345678`,
UART re-init + GPIO6/7 toggle exist in **both** versions (see `VNSD_FC41D_Hamedata_Customizations.md`).

## 4. Assessment
* Security-relevant: 202512 = **one-way street** (ECDSA signature check, no downgrade to A04 via QWLANOTA).
* Dropping web config/AirKiss reduces the module's attack surface (no local HTTP server any more).
* Future images remain decryptable (same AES RBL wrapper, signature only wraps it) – see `security/` (local only, not in the repo).
